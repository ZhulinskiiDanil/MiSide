# Чек-лист перед релизом

[English](CHECKLIST.md)

Пройти вручную в игре перед релизом. В каждой строке: что сделать, затем что должно получиться.

**Основное**

- [x] Открыть игру: тёмная сцена с малиновым свечением справа, логотип и «ГЛАВНОЕ МЕНЮ» над компактной колонкой фиолетовых плашек слева, ВЫХОД отдельно внизу, карточка профиля слева внизу, строка лотка справа внизу; ванильного заголовка, фона с иконками, больших кнопок, кнопки профиля, ника и соцсетей не видно
- [x] Каждый пункт открывает то же, что его ванильная кнопка: Играть → выбор уровней, Гардероб → icon kit, Создать → меню создания, Настройки, Достижения, Статистика, Выход → подтверждение выхода в колонке
- [x] Навести на каждый пункт: подсвечивается вся плашка (без движения), звучит hover; клик в любое место плашки выбирает пункт
- [x] Стрелки двигают ту же подсветку по шести строкам и ВЫХОДУ; если мышь над строкой, стрелки начинают с неё; когда мышь уходит со строк, снова подсвечен выбор клавиатуры; две строки сразу не подсвечиваются никогда
- [ ] Enter (и клик) нажимают ванильную кнопку один раз: без двойного экрана и двойного попапа, даже при быстром двойном нажатии
- [ ] RU и EN: «ДОСТИЖЕНИЯ» / «ACHIEVEMENTS» помещаются в плашку с запасом; размер текста одинаковый у всех пунктов на обоих языках
- [x] Выбрать Настройки и закрыть: затемнение уходит, колонка снова работает
- [x] С попапом поверх меню (кнопки Geode, «…») мышь над колонкой, стрелки и Enter ничего не делают под ним

- [x] Вернуться в меню с каждого экрана: каждый раз новое меню, без оставшегося затемнения
- [ ] На чистой установке в логе нет предупреждений MiSide Menu (`Node ... not found`)
